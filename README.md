# 🦊 尤尤的動物樂園 — 部署指南（零指令版）

為尤尤而設的遊戲式學習網站：**中文**（粵語朗讀課文、閱讀理解、詞語配對、點觸筆順跟寫、無提示默寫、句式練習）＋**常識**（棲息地、健康生活），賺 ⭐ 去經營自己的動物園——探索地區、認識 25 位動物朋友、解決牠們的求助事件、邀請牠們入住、自由佈置園區。中文內容依照**小三**教科書默寫詞彙及句式／寫作目標編寫（初階）。

整個部署過程**不需要打任何指令**，全部在網頁上完成，大約 15 分鐘。流程和「太空中文基地」完全一樣；如果已經部署過那個網站，照辦煮碗即可（**這是另一個新網站，要開一個新的 repo 和新的 Netlify site，並設定新的家庭代碼**）。

## 🧭 一次性設定（只需做一次）

### 第 1 步：把資料夾上載到 GitHub

1. 先把收到的 zip 檔**解壓縮**，得到一個資料夾（入面有 `public`、`netlify`、`netlify.toml`、`package.json`、`README.md`）。
2. 用電腦瀏覽器登入 [github.com](https://github.com)。
3. 按右上角 **「+」→「New repository」**。
4. Repository name 填 `yoyo-zoo`（或任何名），選 **Private**（私人），按綠色 **「Create repository」**。
5. 在新頁面找 **「uploading an existing file」** 這條藍色連結，按進去。
6. 打開電腦上解壓後的資料夾，**全選入面所有檔案和資料夾**（不是選最外層資料夾本身），拖入 GitHub 頁面中間的虛線框。
7. 等全部上載完成後，按下方綠色 **「Commit changes」**。

✅ 完成後，repo 頁面應該見到 `public` 資料夾、`netlify` 資料夾、`netlify.toml` 等。

### 第 2 步：連接 Netlify

1. 去 [app.netlify.com](https://app.netlify.com)，用 **「Sign up with GitHub」** 登入（免費；已有帳號就直接登入）。
2. 按 **「Add new project」→「Import an existing project」→「GitHub」**。
3. 在清單揀啱啱建立的 `yoyo-zoo`。
4. 設定頁乜都唔使改（Build command 留空，Publish directory 會自動讀 `netlify.toml`），直接按 **「Deploy」**。
5. 等 1–2 分鐘，見到 **「Published」** 就代表網站上線，頂部會有你的網址，例如 `https://xxxx.netlify.app`。
   - 想改靚啲個名：Site configuration → Site details → **Change site name**。

### 第 3 步：設定家庭代碼（重要！）

1. 在 Netlify 該網站頁面，左邊選 **「Site configuration」→「Environment variables」**。
2. 按 **「Add a variable」**：
   - Key 填：`FAMILY_CODE`
   - Value 填：為尤尤一家自訂的代碼（例如 `fox2026go`）
   - ⚠️ 請**不要**用銀行、電郵等重要密碼，這個代碼只是用來保護學習進度。
3. 按 **「Create variable」** 儲存。
4. （建議）再加一個預覽代碼：
   - Key 填：`PREVIEW_CODE`
   - Value 填：另一個不同的代碼（例如 `preview2026`）
   - 這個代碼一登入就**全功能開放**——全部章節與地區解鎖、探索免費、批改模式免密碼、五步任意跳，方便老師先行測試。**進度與學生完全分開儲存**，不會影響尤尤的記錄。不設定也可以，網站照樣運作。
5. **必須重新發佈一次才生效**：去 **「Deploys」** 頁，按 **「Trigger deploy」→「Deploy site」**，等 1 分鐘。

### 第 4 步：驗收

1. 打開 `https://你的網址/check.html`，輸入家庭代碼，按 **「開始檢查」**。
2. 七項全部 ✓ 就大功告成！
3. 之後打開主頁，輸入家庭代碼就可以開始。

### 📱 iPad 貼士：加到主畫面

用 Safari 打開網站 → 按分享掣（⬆️）→ **「加入主畫面」**。之後就好似一個 App 咁，全螢幕使用。

## 🔬 醫學／科學內容覆核清單（請過目）

遊戲內全部動物知識與護理內容，建站時已逐項對照公認資料核實；以下列出**每一項事實聲明**方便你覆核。如需修改，全部集中在 `public/js/data.js` 的 `animals` 段落。

**求助事件（10 個）**
1. 狗×朱古力：朱古力含可可鹼，狗難以代謝，不可餵食；誤食應盡快求醫。洋葱、提子同屬危險食物。✔ 獸醫界共識
2. 貓×毛球：舔毛吞入脫毛成毛球；定期梳毛可減少；持續嘔吐或拒食須看獸醫。✔
3. 兔×牙齒過長：門牙終生生長；乾草任食磨牙；拒食＋流口水是牙科典型徵狀；修牙須由獸醫處理；紅蘿蔔高糖只作點心。✔
4. 金魚×水質：餵食過量污染水質；少量多餐＋定期部分換水。✔
5. 大象×泥浴：屬正常行為——防曬、防蟲、降溫；應提供泥池水池樹蔭。✔
6. 海龜×膠袋：膠袋水中形似水母，誤吞阻塞消化道；減少即棄塑膠。✔ 海洋保育共識
7. 企鵝×換毛：換毛期羽毛失去防水，留岸不下水屬正常；換毛前增食儲能。✔
8. 大熊貓×食竹：竹營養低，每日進食十多小時屬正常；需大量鮮竹並定期檢查牙齒。✔
9. 刺蝟×秋肥：野生刺蝟冬眠前增重鋪巢屬正常；冬眠不應打擾；刺蝟乳糖不耐，不可餵牛奶。✔
10. 北極熊×過熱：厚毛厚脂肪耐寒怕熱；喘氣呆滯可為過熱徵狀；供應冰塊、凍水池、陰涼。✔

## 📚 課程內容

- 詞彙：小三默寫詞彙表 100 詞中選用 49 個（6 章 × 8 詞、第 6 章 9 詞），**跨章不重複**，文章必含該章全部詞語（已用腳本自動驗證）。
- 句式／手法：擬人、比喻、擬聲詞、語氣詞、疑問與反問、遞進（不但…還／而且）、承接（一…便；先…接着…然後）、形容詞擴寫、逐項舉例。
- 寫作目標：遞進句仿作（一章）→ 承接＋疑問（二）→ 擬聲＋語氣詞（三）→ **日記格式**（四）→ **感謝卡格式**（五）→ **記敘文六要素**段落（六）。
- 常識：〈動物的家在哪裏？〉（棲息地）、〈做個健康的小朋友〉（衞生・飲食・運動・睡眠）。**待尤尤的常識課本單元到手後，可照同一格式加章**（每章只需 article＋questions，`type: "gs"`）。

> ⚠️ `data.js` 同 `strokes.js` 係孖生檔案：任何詞語改動，兩個檔案要一齊更新（更新方法：交返俾我重新生成）。
